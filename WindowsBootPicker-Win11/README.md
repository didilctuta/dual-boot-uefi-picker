# Windows 启动切换器

Windows 11 上的图形工具，用于从已有的 UEFI 固件启动项里选择 Windows 或 Ubuntu。

## 文件

- `启动切换器.exe`：推荐的无命令窗口启动入口。
- `WindowsBootPicker.ps1`：图形界面与启动项操作脚本；运行 EXE 时必须与其放在同一目录。
- `启动切换器.vbs`：无命令窗口的备用入口，同样依赖 PowerShell 脚本。
- `Launcher.cs`：EXE 启动器源码，不参与日常运行。

## 使用

下载并保留本目录中的文件，双击 `启动切换器.exe`。Windows 会请求管理员权限，因为读取和修改固件启动项需要提升权限。启动器不会打开命令窗口；若初始化报错，会弹窗显示错误。如果不使用 EXE，也可双击 `启动切换器.vbs`。

- **设为默认启动**：把当前下拉框选择的系统移到 UEFI 固件启动顺序首位，持续生效。
- **下次启动进入所选系统**：设置一次性启动目标，设置后不会立即重启。
- **现在重启**：单独确认后才重启。

应用通过 `bcdedit /enum firmware /v` 读取固件项，并使用 `{fwbootmgr}` 的 `displayorder` / `bootsequence` 设置默认和下一次启动项。它只显示能通过描述或 EFI 路径识别为 Windows Boot Manager、Ubuntu 的项目，不创建或删除启动项。若当前只识别到一个系统，仍可打开窗口，但不能借此创建缺失的启动项。

## 限制

- 机器需要以 UEFI 模式启动，并且固件枚举中已有要选择的启动项。此工具不适用于 Legacy BIOS 启动。
- 需要 Windows 11 和系统自带的 Windows PowerShell 5.1。
- 没有 Ubuntu 项时，窗口仍会打开并显示检测到的系统；若固件读取失败，窗口会提示错误，设置按钮保持禁用。
- Windows 版需以管理员权限运行。
- 无本地显示器时，可通过远程桌面操作该窗口；纯 SSH/远程 PowerShell 环境没有交互式下拉界面。
- 首次使用先不要自动重启；设置后可核对提示，再手动重启。服务器应确保目标系统的远程访问可用。
